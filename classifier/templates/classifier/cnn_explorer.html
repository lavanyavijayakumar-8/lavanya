Mathematical Mechanics of CNNs

1. 2D Spatial Discrete Cross-Correlation

Convolution applies learnable parameter kernels $K \in \mathbb{R}^{k \times k}$ across input feature maps $X$:

S(i, j) = (X * K)(i, j) = ∑m ∑n X(i + m, j + n) ⋅ K(m, n) + b

2. Softmax Probability Normalization

Converts raw real-valued logit scores $z_i$ into a valid categorical probability distribution:

P(y = c | X) = exp(zc) / ∑j=1C exp(zj)

3. Grad-CAM (Gradient-Weighted Class Activation Mapping)

Computes the gradient of score $y^c$ with respect to activation map $A^k$ of the final conv layer:

αkc = (1/Z) ∑i ∑j (∂yc / ∂Ai,jk)
LGrad-CAMc = ReLU( ∑k αkc Ak )
