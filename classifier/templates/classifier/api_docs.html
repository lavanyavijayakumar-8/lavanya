Developer Reference

RESTful Classification API

Integrate our multi-domain CNN classification engine directly into your IoT edge devices, mobile apps, agricultural sensors, or laboratory systems via standard HTTP POST.

POST /api/classify/

Submits an image for automated Convolutional Neural Network inference, returning class predictions, confidence percentages, latency benchmarks, and Grad-CAM heatmap URLs.

Accepted Parameters

Parameter Type Required Description
image File (Multipart) Conditional Image file stream (JPEG, PNG, WebP)
image_base64 String (JSON) Conditional Base64-encoded image string
sample_id Integer Conditional ID of preloaded demo sample image
domain String Optional Target scope: auto, plants, animals, vehicles, waste, medical

Integration Code Snippets

cURL (Command Line)
curl -X POST http://127.0.0.1:8000/api/classify/ \
  -F "image=@sample_leaf.jpg" \
  -F "domain=plants"
Python (requests)
import requests

url = "http://127.0.0.1:8000/api/classify/"
files = {"image": open("sample_xray.jpg", "rb")}
data = {"domain": "medical"}

response = requests.post(url, files=files, data=data)
result = response.json()
print("Prediction:", result["prediction"]["class_name"])
print("Confidence:", result["prediction"]["confidence_percentage"], "%")
JavaScript (Fetch API)
const formData = new FormData();
formData.append('image', fileInput.files[0]);
formData.append('domain', 'auto');

const res = await fetch('/api/classify/', {
  method: 'POST',
  body: formData
});
const data = await res.json();
console.log(data);
